إعدادات قاعدة البيانات السحابية الموحدة

لكي يرى جميع المعيدين ومنسق الجودة البيانات في نفس اللحظة من أي جهاز في العالم، يستخدم النظام قاعدة بيانات Firebase Realtime Database المجانية من Google.

كيف تحصل على رابط مجاني في دقيقة واحدة؟
  1. ادخل إلى console.firebase.google.com وسجل بحساب Google.
  2. اضغط Add project ثم اختر Realtime Database واضغط Create Database في وضع الاختبار (Test Mode).
  3. انسخ رابط قاعدة البيانات (ينتهي بـ .firebasedatabase.app) وألصقه بالأسفل.
